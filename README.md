# 🧊 مسح 3D → طباعة

موقع ويب يعمل بالكامل على الآيفون (وأي جهاز آخر): يساعدك تمسح الأجسام ثلاثيًا، تفحص النموذج وتجهّزه، وتحسب المواد والتكلفة والوقت للطباعة ثلاثية الأبعاد. الفحص والتجهيز والحسابات كلها داخل المتصفح؛ وتحويل الصور إلى نموذج 3D يتم **على كمبيوترك المنزلي مجانًا** عبر RealityScan.

## المزايا

### 📷 المسح (Photogrammetry)
- التقاط موجّه بالكاميرا الخلفية مع عدّاد تغطية دائري يعتمد على حساس الاتجاه (بوصلة الآيفون)
- **💻 معالجة على جهازك مجانًا**: زر واحد يرسل الصور إلى كمبيوترك المنزلي ليعالجها RealityScan تلقائيًا ويرجع نموذج 3D يفتح في المعاينة — مع مؤشر مباشر لحالة اتصال الكمبيوتر 🟢/🔴 (انظر مجلد `agent/`)
- تصدير الصور دفعة واحدة بصيغة ZIP جاهزة للمعالجة اليدوية في RealityScan / Meshroom / COLMAP
- نصائح مدمجة لأفضل نتيجة مسح

> ملاحظة: متصفح سفاري لا يسمح بالوصول المباشر لحساس LiDAR — هذا حصري للتطبيقات الأصلية. لذلك الموقع يدعم مسارين: التصوير المساحي عبر الكاميرا، أو استيراد ناتج أي تطبيق مسح (Polycam, Scaniverse, RealityScan…).

### 🧊 الاستيراد والمعاينة
- يدعم **STL · OBJ · GLB/GLTF · PLY · USDZ**
- عارض ثلاثي الأبعاد (three.js) مع سطح طباعة افتراضي وشبكة سلكية
- كشف تلقائي لوحدات القياس (متر/ملم) مع تحويل تلقائي لملفات GLB/USDZ

### 🔎 فحص قابلية الطباعة
- الأبعاد والحجم ومساحة السطح وعدد المثلثات
- كشف الثقوب (الحواف المفتوحة) والحواف غير السليمة (non-manifold)
- حكم فوري: جاهز للطباعة ✅ / يحتاج إصلاح ❌

### 🛠️ التجهيز
- تحويل الوحدات (متر/إنش/سم → ملم) والتحجيم لأكبر بُعد مستهدف
- تدوير حول المحاور + إنزال على سطح الطباعة وتوسيط
- إعادة حساب اتجاهات الأسطح (مع كشف الأسطح المعكوسة) ودمج النقاط المكررة
- تصدير: **STL (ثنائي) · 3MF · OBJ** — بالملليمتر، جاهز لأي برنامج تقطيع

### 🧮 حسابات الطباعة
- خامات FDM (‏PLA, PETG, ABS, ASA, TPU, نايلون) وريزن — مع الكثافة وحرارات الطباعة المقترحة
- حساب الخامة المطلوبة (يشمل الجدران ونسبة التعبئة)، الوزن، أمتار الفتيل، التكلفة، والوقت التقديري
- وضع ريزن: عدد الطبقات والوقت حسب ارتفاع الطبقة

### 🖼️ معرض المسحات (اختياري)
- كل نموذج ناتج يُحفظ تلقائيًا في تخزين دائم (Supabase)، فيظهر في تبويب «المعرض» على الجوال
- افتح أي مسحة سابقة في أي وقت، أو احذفها — يظهر التبويب فقط إذا فعّلت التخزين

### 📱 PWA
- يعمل بدون اتصال بعد أول زيارة، ويُضاف إلى الشاشة الرئيسية كتطبيق (شارك ← إضافة إلى الشاشة الرئيسية)

## التشغيل

```bash
npm install
npm start          # يفتح على http://localhost:8000
```

الواجهة نفسها ملفات ثابتة وتعمل من أي استضافة، لكن **المعالجة على جهازك** تحتاج خادم Node الصغير (`server.js`) لأنه يدير طابور المهام ويربط الآيفون بكمبيوترك. بدون الخادم، بطاقة المعالجة تختفي تلقائيًا ويبقى كل شيء آخر يعمل.

**النشر على Render** (Web Service وليس Static Site):

| الحقل | القيمة |
|---|---|
| Type | **Web Service** |
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `node server.js` |
| Environment Variable | `AGENT_TOKEN` = سر عشوائي طويل |

أو استخدم **New → Blueprint** وملف `render.yaml` يضبط كل شيء ويولّد `AGENT_TOKEN` تلقائيًا.

**معالجة الصور على جهازك (بدون أي خدمة خارجية):**
1. حمّل RealityScan 2.0 مجانًا من [realityscan.com/download](https://www.realityscan.com/download)
2. انسخ قيمة `AGENT_TOKEN` من Render، وشغّل الوكيل على كمبيوترك — التفاصيل الكاملة في [`agent/README.md`](agent/README.md)
3. من جوالك سترى 🟢 «الكمبيوتر متصل» وتقدر ترسل الصور للمعالجة بضغطة زر

> ⚠️ الكاميرا وحساس الاتجاه يتطلبان **HTTPS** — Render يوفرها تلقائيًا.
> 💤 على خطة Render المجانية يدخل الخادم في سبات بعد 15 دقيقة خمول — أول زيارة بعده تأخذ ~50 ثانية.

**المعرض الدائم عبر Supabase (اختياري، مجاني بدون بطاقة):**
1. أنشئ حسابًا ومشروعًا في [supabase.com](https://supabase.com) (خطة مجانية، بدون بطاقة)
2. من **Storage** أنشئ حاوية (Bucket) باسم `scans`
3. من **Settings → API** انسخ `Project URL` ومفتاح `service_role`
4. في Render أضف متغيّرين: `SUPABASE_URL` و`SUPABASE_SERVICE_KEY`، ثم أعد النشر
5. بعدها كل مسحة تُحفظ تلقائيًا ويظهر تبويب «المعرض» في الجوال. بدون هذه المتغيرات يبقى كل شيء يعمل والمعرض مخفي فقط.

## طريقة الاستخدام من الآيفون

1. **امسح**: افتح تبويب «المسح»، شغّل الكاميرا، لُف حول الجسم والتقط 40–80 صورة
2. **عالج**: اضغط «💻 أرسل للمعالجة على جهازي» (يعالجها كمبيوترك ويفتح النموذج تلقائيًا)، أو صدّر ZIP وعالجه يدويًا، أو استورد ناتج تطبيق مسح مثل Polycam من تبويب «المعاينة»
3. **جهّز**: صحّح الوحدات والاتجاه، أصلح الاتجاهات، وصدّر STL أو 3MF
4. **احسب**: اختر الخامة والإعدادات وشاهد الوزن والتكلفة والوقت
5. **اطبع**: افتح الملف المصدَّر في برنامج التقطيع (Cura / PrusaSlicer / Bambu Studio) واطبع 🎉

## البنية

```
index.html            الواجهة (عربي RTL، تصميم موبايل أولًا)
css/app.css           التنسيقات
server.js             خادم Express: ملفات ثابتة + طابور مهام + مسارات المعرض
storage.js            تخزين المسحات الدائم (Supabase) مع وضع معطّل/ذاكرة تلقائي
js/app.js             الربط الرئيسي: استيراد، فحص، تجهيز، تصدير
js/capture.js         الكاميرا والتقاط الصور وعدّاد التغطية و ZIP
js/local.js           المعالجة على الجهاز: رفع، متابعة حالة الاتصال، تنزيل وفتح النموذج
js/gallery.js         معرض المسحات المحفوظة: عرض، فتح، حذف
js/modelzip.js        مساعد مشترك: فكّ ZIP النموذج وفتحه في العارض
js/viewer.js          العارض ثلاثي الأبعاد (three.js)
js/analysis.js        فحص الشبكة: حجم، مساحة، ثقوب، watertight
js/exporters.js       مصدّرات STL / OBJ / 3MF
js/calc.js            حسابات الخامة والتكلفة والوقت
js/materials.js       بيانات الخامات
sw.js                 Service Worker للعمل بدون اتصال
agent/                وكيل الكمبيوتر (PowerShell) + أمر RealityScan + دليل الإعداد
vendor/               three.js و fflate (مضمّنة — لا حاجة لإنترنت أو CDN)
```

### مسار المعالجة على جهازك
1. المتصفح يصغّر الصور إلى 2048px ويرفعها إلى `/api/local/upload` (تدخل طابور المهام)
2. الوكيل على كمبيوترك ينبض عبر `/api/agent/heartbeat` (فيعرف الموقع أنه 🟢 متصل)، ويسحب المهمة من `/api/agent/next`
3. الوكيل ينزّل الصور، يشغّل RealityScan، ويرفع النموذج عبر `/api/agent/result/:id`
4. المتصفح يتابع `/api/local/status/:id` (ويستأنف تلقائيًا لو أغلقت الصفحة)، وعند الاكتمال ينزّل النتيجة ويفتحها في العارض
5. مسارات الوكيل محمية بتوكن `AGENT_TOKEN` — لا أحد غير كمبيوترك يسحب مهامًا أو يرفع نتائج

التقديرات الحسابية تقريبية للتخطيط والتسعير — برنامج التقطيع يعطي الأرقام النهائية الدقيقة.
