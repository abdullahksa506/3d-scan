# 🧊 مسح 3D → طباعة

موقع ويب يعمل بالكامل على الآيفون (وأي جهاز آخر): يساعدك تمسح الأجسام ثلاثيًا، تفحص النموذج وتجهّزه، وتحسب المواد والتكلفة والوقت للطباعة ثلاثية الأبعاد — **بدون سيرفر، كل المعالجة داخل المتصفح**.

## المزايا

### 📷 المسح (Photogrammetry)
- التقاط موجّه بالكاميرا الخلفية مع عدّاد تغطية دائري يعتمد على حساس الاتجاه (بوصلة الآيفون)
- تصدير الصور دفعة واحدة بصيغة ZIP جاهزة للمعالجة في RealityScan / Meshroom / COLMAP
- نصائح مدمجة لأفضل نتيجة مسح

> ملاحظة: متصفح سفاري لا يسمح بالوصول المباشر لحساس LiDAR — هذا حصري للتطبيقات الأصلية. لذلك الموقع يدعم مسارين: التصوير المساحي عبر الكاميرا، أو استيراد ناتج أي تطبيق مسح (Polycam, Scaniverse, RealityScan…).

### 🧊 الاستيراد والمعاينة
- يدعم **STL · OBJ · GLB/GLTF · PLY · USDZ**
- عارض ثلاثي الأبعاد (three.js) مع سطح طباعة افتراضي وشبكة سلكية
- كشف تلقائي لوحدات القياس (متر/ملم) مع تحويل تلقائي لملفات GLB/USDZ

### 🔎 فحص قابلية الطباعة
- الأبعاد والحجم ومساحة السطح وعدد المثلثات
- كشف الثقوب (الحواف المفتوحة) والحواف غير السليمة (non-manifold)
- حكم فوري: جاهز للطباعة ✅ / يحتاج إصلاح ❌

### 🛠️ التجهيز
- تحويل الوحدات (متر/إنش/سم → ملم) والتحجيم لأكبر بُعد مستهدف
- تدوير حول المحاور + إنزال على سطح الطباعة وتوسيط
- إعادة حساب اتجاهات الأسطح (مع كشف الأسطح المعكوسة) ودمج النقاط المكررة
- تصدير: **STL (ثنائي) · 3MF · OBJ** — بالملليمتر، جاهز لأي برنامج تقطيع

### 🧮 حسابات الطباعة
- خامات FDM (‏PLA, PETG, ABS, ASA, TPU, نايلون) وريزن — مع الكثافة وحرارات الطباعة المقترحة
- حساب الخامة المطلوبة (يشمل الجدران ونسبة التعبئة)، الوزن، أمتار الفتيل، التكلفة، والوقت التقديري
- وضع ريزن: عدد الطبقات والوقت حسب ارتفاع الطبقة

### 📱 PWA
- يعمل بدون اتصال بعد أول زيارة، ويُضاف إلى الشاشة الرئيسية كتطبيق (شارك ← إضافة إلى الشاشة الرئيسية)

## التشغيل

الموقع ملفات ثابتة فقط — لا يحتاج بناء ولا سيرفر خاص:

```bash
# محليًا
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**النشر على GitHub Pages** (الأسهل):
1. من إعدادات المستودع → Pages
2. Source: **Deploy from a branch** → اختر الفرع → مجلد `/ (root)`
3. افتح الرابط من سفاري على الآيفون

> ⚠️ الكاميرا وحساس الاتجاه يتطلبان **HTTPS** — GitHub Pages يوفرها تلقائيًا.

## طريقة الاستخدام من الآيفون

1. **امسح**: افتح تبويب «المسح»، شغّل الكاميرا، لُف حول الجسم والتقط 40–80 صورة، صدّر ZIP وعالجه في تطبيق photogrammetry (أو امسح مباشرة بتطبيق مثل Polycam)
2. **استورد**: افتح النموذج الناتج (STL/OBJ/GLB/USDZ) في تبويب «المعاينة» وشاهد نتيجة الفحص
3. **جهّز**: صحّح الوحدات والاتجاه، أصلح الاتجاهات، وصدّر STL أو 3MF
4. **احسب**: اختر الخامة والإعدادات وشاهد الوزن والتكلفة والوقت
5. **اطبع**: افتح الملف المصدَّر في برنامج التقطيع (Cura / PrusaSlicer / Bambu Studio) واطبع 🎉

## البنية

```
index.html            الواجهة (عربي RTL، تصميم موبايل أولًا)
css/app.css           التنسيقات
js/app.js             الربط الرئيسي: استيراد، فحص، تجهيز، تصدير
js/capture.js         الكاميرا والتقاط الصور وعدّاد التغطية و ZIP
js/viewer.js          العارض ثلاثي الأبعاد (three.js)
js/analysis.js        فحص الشبكة: حجم، مساحة، ثقوب، watertight
js/exporters.js       مصدّرات STL / OBJ / 3MF
js/calc.js            حسابات الخامة والتكلفة والوقت
js/materials.js       بيانات الخامات
sw.js                 Service Worker للعمل بدون اتصال
vendor/               three.js و fflate (مضمّنة — لا حاجة لإنترنت أو CDN)
```

التقديرات الحسابية تقريبية للتخطيط والتسعير — برنامج التقطيع يعطي الأرقام النهائية الدقيقة.
